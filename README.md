# Momentum Productivity App

## Overview
The Momentum app is designed to enhance productivity by helping users manage tasks, habits, goals, and focus sessions. The app provides a user-friendly interface and a variety of features to support users in achieving their personal and professional objectives.

## Features
- **Task Management**: Create, edit, and organize tasks with due dates and priorities.
- **Habit Tracking**: Monitor daily habits and track progress over time.
- **Goal Setting**: Set and manage personal and professional goals with milestones.
- **Focus Sessions**: Utilize a Pomodoro timer to enhance focus and productivity.
- **Analytics**: View productivity statistics and trends to improve performance.
- **User Authentication**: Secure login and registration process.

## Technology Stack
- **React Native**: For building the mobile application.
- **TypeScript**: For type safety and better development experience.
- **Redux**: For state management.
- **React Navigation**: For navigating between screens.
- **Axios**: For making API calls.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd momentum
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Run the application:
   ```
   npm start
   ```
