# Roadmap

## Planned Features
- [ ] **Offline Sync Queue**: Robust local SQLite queue for task edits and completions made without network connectivity.
- [ ] **Interactive Widget Support**: iOS WidgetKit and Android AppWidget for quick habit and task toggling.
- [ ] **End-to-End Encrypted Backups**: Optional client-side encryption for personal journal notes before syncing.
- [ ] **Wearable Focus Integration**: Watch companion app for starting and tracking focus timers.
